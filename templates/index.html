Update layers across all template sizes -- fill any of these in and, on every template-covered size whose PSD has a matching named layer (header, description, logo, cta, product, background), the new content is composited into that layer's exact position for that size -- a different position/scale per size, since each template has its own layout. A size whose PSD doesn't have a given layer just skips that one update. The logo/CTA/product images are pasted in (contain-fit, centered, background removed); the background image fills its layer completely (cropped to fit, no cutout removal -- it's meant to be the full frame, not an object sitting within it); header/description are painted over and redrawn with your text, since Pillow can't edit a PSD's live text layer directly. These are PSD updates only -- they don't affect the general hero-image tool below.
